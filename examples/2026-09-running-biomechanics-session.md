# 2026-09 Running Biomechanics Carousel — Session Learnings

## 주제

팔치기와 ‘리듬’ 코칭을 생체역학과 운동제어 관점에서 검토한 18장 인스타그램 캐러셀.

## 이번 세션에서 확정된 개선

1. 초기 표지는 스케치·설명·수치가 많아 지저분했다.
2. 이후 생성 이미지를 줄이고 제목을 키웠으나, 본문성 문장이 여전히 많았다.
3. 최종 방향은 **세로 4:5 / Pretendard / 텍스트 중심 / 유튜브 썸네일 수준의 즉시성**이다.
4. `팔치기, 리듬`처럼 주제어를 가장 크게 두고 단일 accent로 대비한다.
5. 생성 이미지는 선택 사항이다. 넣을 경우 단일 러너처럼 하나의 역할만 맡긴다.
6. `IO MAGAZINE × 장호준`은 표지와 엔딩의 고정 브랜드 크레딧으로 사용한다.
7. 마지막 장은 `팔로우 · 저장 · 공유` + `궁금한 것은 댓글` + `다른 의견/반박/논쟁 환영`으로 단순화한다.

## 카피에서 배운 점

초기 문구:
`팔치기랑 리듬을 구체적으로 설명하는 사람의 지식은 0%에 수렴한다.`

문제:
- 실제 측정값인 0%처럼 읽힌다.
- 내용보다 사람을 공격한다.
- 이후 생체역학 근거와 연결성이 약해진다.

개선 방향:
- 사람의 능력 평가 대신 **잘못된 설명 방식**을 공격한다.
- `왜 필요한지도 모르고 경험으로 반복하는 코칭`처럼 검토 가능한 행동을 대상으로 한다.
- 표지에서는 모든 근거를 설명하지 않고 본문으로 넘긴다.

## 디자인에서 배운 점

- 한 장에 큰 제목 + 긴 부제 + 러너 + 화살표 + 영문 태그 + 하단 설명을 동시에 넣으면 실패한다.
- 큰 제목을 살리려면 나머지는 삭제하는 쪽이 낫다.
- off-white/black/accent 한 색 조합이 이번 시리즈에 적합했다.
- Pretendard 계열의 굵은 산세리프가 타이틀에 적합하다.
- 이미지가 없어도 강한 표지가 가능하다.
