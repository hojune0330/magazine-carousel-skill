# IO MAGAZINE Report Carousel Skill

전용 인스타그램 4:5 세로형 카드뉴스 제작 스킬입니다.

## Active profile

- `report-carousel-v2`
- 기준: 사용자가 승인한 **11~20장 규격**
- 폐기: **1~10장 규격**

## 핵심 특징

- 제목 위치·크기 고정
- 부제목 위치·크기 고정
- 본문 크기·줄간격 고정
- 표 규격 고정
- 페이지 번호와 크레딧 위치 고정
- 원문 보존 요청 시 한 글자도 삭제·교정·요약하지 않음
- 사진이 들어가도 헤더·제목·푸터 골격 유지
- 텍스트가 넘치면 글자를 줄이지 않고 다음 장으로 분할
