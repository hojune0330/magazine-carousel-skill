# Request Routing v3.3 — 짧은 지시의 실제 의미

## 파일 렌더링

`스킬대로 / 파일로 / 렌더링 / 전체 20장 / PNG·ZIP / 이어서 / 원문 빠짐없이`는 전체 파일 제작이다. 생성형 포스터 도구로 전환하거나 10장으로 끊지 않는다.

## 원문 중심

`글 전부 / 단어 그대로 / 문장구성 그대로 / 요약하지 마 / 표·그래프는 부가적 / 사진은 쓰되 글자 위주`는 선택 원문을 모두 공개 슬라이드에 담으라는 뜻이다. 요약 슬라이드+원문 첨부파일로 대체하지 않는다.

`지금 만든 수준이 딱 좋다`는 승인한 실제 출력과 스타일을 계승하라는 뜻이다. 예전 사진 중심 템플릿이나 더 작은 본문 프리셋으로 돌아가지 않는다. 신규 기본은 본문 26/39이며 장별 축소하지 않는다.

## 불필요한 문구 제거

`위에 풀 텍스트 / 아래 원문은 파일에 수록 / 관객에게 보이면 안 돼`는 **슬라이드 이미지 속 제작 메타정보를 제거**하라는 지시다. 결과 안내문을 줄이라는 뜻이 아니다.

- public: 콘텐츠 제목·본문·표·필수 출처·사진 크레딧.
- production: 원문 보존 설명, 첨부파일 안내, QA, 제작 방식. 보고서·전달 메시지 허용.
- internal: 해시·매니페스트·디버그 로그.

`보고서에는 있어도 돼`를 무시하고 작업 기록을 지우지 않는다.

## 사진과 자료 조사

`이미지도 잘 붙여 / 이미지 자료 조사 / 사진 부족하면 알아서`는 본문을 확보한 뒤 관련 자료를 조사·선별하라는 뜻이다. 모든 페이지에 사진을 강제하지 않는다.

업로드 → 필요도 정의 → 실제 원본/근거 조사 → 권리·해상도·중복 확인 → 남은 공간 배정 → 캡션·출처 → 검사 순으로 진행한다. 상세는 image-research-and-placement.md를 따른다.

## 표·그래프

원래 표는 원문으로 보존한다. 추가 그래프는 보조이며 문장을 없애지 못한다. 표 페이지에는 사진이 없다. 데이터 출처가 불명확하면 가짜 그래프를 만들지 않는다.

## 생성 금지

`이미지 생성 기능 쓰지 말고`는 생성형 AI 보조 에셋까지 금지한다. Python/SVG로 정확한 표·그래프·도형을 렌더링하는 것은 생성형 이미지 사용이 아니다. `내가 준 사진만`은 외부 이미지 확보도 금지한다.

## 구체적인 한국어 문장 — 사용자 재확인 2026-09-07

`추상적인 표현 금지 / 남았다·보인다 같은 말 쓰지 마 / 이런 뉘앙스 기억하라고 했잖아`는 단어 몇 개만 교체하라는 뜻이 아니다. 새로 쓰는 제목·부제·캡션·기획안·설명에서 **누가, 언제, 어디서, 무엇을 했는지 또는 어떤 측정값이 얼마나 달라졌는지**를 명시한다.

### 기본 문장 규칙

- 제목만 읽어도 대상과 비교 기준을 파악할 수 있게 쓴다. 수치 비교라면 대회·연도·집계 대상을 제목과 부제 안에서 명시한다.
- 변화 동사는 측정 대상과 연결한다: 착용률이 하락했다, 착용자가 증가했다, 매출이 증가했다, 기록이 단축됐다, 계약을 체결했다.
- `남았다`, `보인다`, `존재감을 키웠다`, `판도가 바뀌었다`, `발밑에서 경쟁한다`, `기준을 남긴다`처럼 사실 대신 분위기를 전달하는 문장을 새 카피에 쓰지 않는다.
- `상위권`은 TOP10·4위·상위 3% 등 해당 자료가 정의한 범위로 쓴다. `선수층`은 기준 기록 이내 선수 수 등 실제 측정값과 함께 쓴다.
- `성장했다`는 매출·착용자 수·착용률·매장 수 중 어떤 항목인지 명시한다. 서로 다른 지표를 같은 성장률처럼 비교하지 않는다.
- 질문형 훅도 미확인 사실을 전제하지 않는다. 증가 자료 없이 `왜 늘었을까?`, 전환 조사 없이 `왜 갈아탔을까?`라고 쓰지 않는다.
- 흥미는 확인한 순위·비율·격차·상반된 결과에서 만든다. 과장된 은유나 대상 없는 짧은 동사로 만들지 않는다.

### 표현 교정 예시

- 지양: `몇 년 뒤, 6명 중 1명만 남았다.`
- 사용: `<대회>의 <브랜드> 착용률이 <기준연도 A%>에서 <비교연도 B%>로 하락했다.`
- 지양: `써코니의 성장이 보인다.`
- 사용: `<대회·연도>의 <집계 대상> 중 써코니 착용자는 N명, 착용률은 X%였다.`
- 지양: `빠른 러너들이 써코니로 갈아탔다.`
- 사용: 개인별 이전 착용 브랜드를 조사하지 않았다면 `해당 표본에서 써코니의 착용률은 X%였다.`
- 지양: `신발이 기록을 바꿨다.`
- 사용: 비교 실험의 대상·조건·측정값을 제시하고, 기록 단축을 측정하지 않았다면 기록 단축 효과라고 쓰지 않는다.

위 숫자 기호는 문장 형식 예시이며 실제 게시물에는 검증한 값만 넣는다.

### 불확실성과 원문 보존

- 모호한 `~로 보인다`를 근거 없는 확신으로 바꾸지 않는다. `공개 원자료를 확인하지 못했다`, `이 자료로 원인을 확정할 수 없다`, `조사자의 해석이다`처럼 불확실한 항목을 정확히 쓴다.
- 화면·사물의 가시성 등 실제 의미가 필요한 인용문을 기계적으로 바꾸지 않는다. 사용자가 보존하도록 지정한 원문과 직접 인용은 자동 수정하지 않고 새 편집 카피에 이 규칙을 적용한다.
- 금지 표현 검토는 기획안·슬라이드 카피·캡션·결과 설명을 제출하기 전에 수행한다. 확인되지 않은 수치를 채워 문장 형식만 완성하지 않는다.

## 대회 러닝화 착용률 주제의 원자료 검사

사용자가 `아마 3위나 4위일 것`, `내가 알기로는`처럼 말한 수치는 조사 단서이지 확정값이 아니다.

1. 대회명·개최연도, 조사자, 조사 날짜, 표본 수를 확인한다.
2. 참가자 전체 / 서브3 완주자 / 남녀 / 출발 그룹 / 특정 구간 통과자 중 무엇을 집계했는지 구분한다. 서브3는 3시간 미만 완주 기준으로 명시하되 원자료의 건타임·넷타임 기준을 따른다.
3. 브랜드별 착용률과 모델별 착용률을 구분한다. 완주자 전수와 사진·영상으로 식별한 표본을 혼동하지 않는다.
4. 착용률은 매출 점유율이나 신발 성능 순위가 아니다. 서로 다른 대회의 비율은 각 대회 내부 비교로 제시하고 한 시계열로 합치지 않는다.
5. 연도별 착용자 집단이 다르면 기존 사용자의 브랜드 전환을 입증하지 못한다.
6. 원자료가 없으면 해당 수치·순위·증가 주장을 미확정으로 분리한다. 링크 또는 캡처를 한 번 요청할 수 있다.
7. 브랜드·학교·선수의 계약 및 제공 여부는 확인한 자료만 제시한다. 후원 이력이 있다는 이유만으로 신발 선택이 강제됐다고 단정하지 않는다.
8. 원자료가 확인된 뒤 해당 기간의 출시 모델·후원·유통·기술 자료와 대조한다. 인과관계는 착용률만으로 확정하지 않는다.

## 특정 장 수정

`2·3장만 다시`는 해당 장의 내용·원문 범위와 번호를 유지하며 레이아웃을 수정한다. 나머지 장은 바꾸지 않는다. 원문 재분할이 다른 장에 영향을 주면 전체 연결부를 점검한다.

## GitHub 업데이트

실제 문서를 읽고 변경한 뒤 커밋·readback 확인을 수행한다. 정리문만 보여주고 저장했다고 하지 않는다. 스킬 업데이트와 기존 PNG 재렌더링, 새 채팅 자동 로드는 서로 다른 작업이다.
