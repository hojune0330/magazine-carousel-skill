# QA Checklist — Report Carousel v2

완료 전 아래 항목을 모두 확인한다.

## Layout

- [ ] 캔버스가 1080×1350 (4:5)인가
- [ ] 좌우 여백이 일관적인가
- [ ] 노란 세로 바 위치가 동일한가
- [ ] 영문 라벨 위치와 크기가 동일한가
- [ ] 제목 시작 위치가 모든 장에서 동일한가
- [ ] 제목 크기·굵기·줄간격이 동일한가
- [ ] 부제목 크기와 굵기가 동일한가
- [ ] 본문 크기와 줄간격이 동일한가
- [ ] 푸터 구분선, 페이지 번호, 크레딧 위치가 동일한가

## Typography

- [ ] 제목을 맞추기 위해 크기를 줄인 장이 없는가
- [ ] 본문을 맞추기 위해 크기나 자간을 과도하게 줄인 장이 없는가
- [ ] 표 안의 같은 역할 텍스트 크기가 동일한가
- [ ] 긴 제목은 크기 축소가 아니라 줄바꿈/페이지 분할로 해결했는가

## Photos

- [ ] 사진 장에서도 헤더·제목·푸터가 이동하지 않았는가
- [ ] 얼굴, 머리, 발, 핵심 동작이 부자연스럽게 잘리지 않았는가
- [ ] 사진 위에 긴 본문을 올리지 않았는가
- [ ] 사진의 밝기와 색온도가 데크 안에서 크게 튀지 않는가
- [ ] 사진이 단순 장식이 아니라 정보 보조 역할을 하는가

## Tables & Data

- [ ] 표가 얇은 선과 정렬 중심으로 구성됐는가
- [ ] 표를 맞추기 위해 글자를 지나치게 줄이지 않았는가
- [ ] 단위, 날짜, 기록, 순위가 원문/출처와 일치하는가
- [ ] 표가 너무 넓으면 2장으로 분할했는가

## Source-preserving mode

- [ ] 원문의 모든 글자·숫자·괄호·각주·URL이 유지됐는가
- [ ] 문장 순서가 유지됐는가
- [ ] 표의 열 이름·행 이름·셀 값이 유지됐는가
- [ ] `text-manifest.txt`와 원문 비교 결과 누락 0인가

## Final visual check

- [ ] 개별 PNG를 모두 확인했는가
- [ ] 전체 콘택트시트에서 1~10장식 불안정한 규격이 섞이지 않았는가
- [ ] 한 장만 유독 글자가 작거나 큰 페이지가 없는가
- [ ] 페이지 번호가 연속적인가
- [ ] 크레딧이 모든 장에 존재하는가

하나라도 실패하면 완료 처리하지 않는다.
