# QA Checklist v3.3 — 원문·공개층·렌더링 분리 검수

각 항목은 pass / fail / not-run / approved-exception으로 기록한다. 하지 않은 검사를 통과 또는 0건으로 표시하지 않는다.

## A. 원문

- [ ] 현재 지시가 가리킨 원문을 잠갔는가? 예전 요약본을 잘못 쓴 것은 아닌가?
- [ ] 제목·소제목·모든 문장·원래 표·각주·URL이 실제 페이지에 있는가?
- [ ] 첨부파일의 전문으로 슬라이드의 누락을 대신하지 않았는가?
- [ ] 사진·그래프로 본문을 대체하지 않았는가?
- [ ] source_ranges가 누락·중복 없이 연결되는가?
- [ ] 재배열은 명시적으로 허용된 경우에만 했는가?
- [ ] 실제 draw-call 문자열과 원문을 대조했는가?

## B. 관객 노출층 — 이번 필수 변경

- [ ] public / production / internal이 분리됐는가?
- [ ] 렌더러가 audience=public의 허용 role만 그렸는가?
- [ ] 헤더에 풀 텍스트, FULL TEXT, 모드명·버전이 없는가?
- [ ] 푸터에 원문 파일 수록, 첨부파일 참조, 검수·QA 문구가 없는가?
- [ ] 본문·표 셀·사진 캡션·차트 범례에도 제작 문구가 없는가?
- [ ] 이미지에 원래 들어 있거나 CSS 가상 요소로 추가된 제작 문구를 확인했는가?
- [ ] 논문 제목, 연구 방법·기간·표본, 자료 한계, 필수 사진 크레딧은 유지했는가?
- [ ] 금지 후보를 발견했다고 원문을 자동 삭제하지 않았는가?
- [ ] 공개 예외는 사유와 승인 참조가 있는가?
- [ ] scripts/lint_public_surface.py를 전후 모두 실행했는가?

## C. 텍스트 중심 스타일

- [ ] 승인된 스타일 또는 새 기본 본문 26px/39px를 사용했는가?
- [ ] 제목 56px·부제목 36px 등 역할별 규격이 전 장 동일한가?
- [ ] 장마다 더 작은 프리셋을 사용하지 않았는가?
- [ ] 제목 시작 좌표·헤더·푸터가 고정돼 있는가?
- [ ] 사진보다 본문 공간을 먼저 확보했는가?
- [ ] 의미 있는 여백을 강제로 채우려고 사진·문장을 반복하지 않았는가?

## D. 이미지 조사와 실제 사용

- [ ] 페이지별 설명 목적을 먼저 정의했는가?
- [ ] 업로드·ZIP과 내려받은 사본의 중복을 제거했는가?
- [ ] 파일이 실제 존재하고 정상 디코딩되는가?
- [ ] 주제·촬영시점·대회가 원문과 맞는가? 다른 사건 사진이면 독자용 캡션으로 구분했는가?
- [ ] 사람의 신원을 얼굴만 보고 추정하지 않았는가?
- [ ] 실제 원본 다운로드와 링크 확인만 한 경우를 구분했는가?
- [ ] 공식 사이트라는 이유만으로 이용권을 단정하지 않았는가?
- [ ] 필요한 작가·라이선스·출처를 기록하고 게시 의무를 지켰는가?
- [ ] 전경 무크롭·가림 없음·기본 1회 사용인가?
- [ ] 관련성이 약한 군중·안내판·보도진·장식 사진을 제외했는가?

## E. 표·그래프·보조물

- [ ] 원래 표의 모든 열·행·셀·각주가 보존됐는가?
- [ ] 표 페이지의 사진 수가 0인가?
- [ ] 표 행의 실제 높이가 글자를 모두 수용하는가?
- [ ] 추가 그래프는 실제 수치·단위·기준·출처를 사용하는가?
- [ ] 보조 도식이 새로운 인과관계를 만들어내지 않았는가?
- [ ] 실제 캡처를 사용했고 출처·페이지·시간코드를 기록했는가?
- [ ] 생성형 보조 에셋 금지 지시를 지켰는가? 코드 그래프와 혼동하지 않았는가?

## F. 픽셀·가독성

- [ ] 모든 glyph가 안전영역 안에 있는가?
- [ ] 우측·하단 잘림, overflow:hidden, mask, 사진·도형 가림이 없는가?
- [ ] 제목 다음 본문·문단 끝·표 분할이 자연스러운가?
- [ ] 실제 PNG 전체를 개별 확대와 모바일 크기로 확인했는가?
- [ ] 콘택트시트의 페이지 순서와 폰트 체계가 일관적인가?

## G. 산출물

- [ ] 요청한 전체 장수의 PNG, 미리보기, ZIP이 실제로 열리는가?
- [ ] source·style·maps·render-surface·매니페스트·출처·감사·검토·QA 문서는 production/에 보관됐는가?
- [ ] 제작 보고서에는 필요한 정보가 있고 관객용 이미지에는 그 안내가 없는가?
- [ ] 현재 검수 범위와 미실행 항목을 정직하게 보고했는가?

`PUBLIC_SURFACE_QA.json`은 텍스트 노출 경계 검사 결과다. 픽셀 잘림 검사나 원문 전체 포함 검사를 대신하지 않는다. 스킬의 단위 테스트 통과가 이미 만든 모든 슬라이드의 통과를 뜻하지 않는다.
