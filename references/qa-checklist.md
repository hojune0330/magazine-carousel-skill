# QA Checklist — Report Carousel v3.2

완료 전 아래 항목을 모두 확인한다.

## 1. Production mode

- [ ] 다장 캐러셀을 결정론적 파일 렌더링으로 만들었는가
- [ ] 요청한 전체 장수를 한 실행에서 렌더링했는가
- [ ] 최종 한국어 본문·표·페이지 번호를 생성형 이미지에 맡기지 않았는가
- [ ] 실제 PNG·ZIP·preview·검수 파일이 존재하는가

## 2. Canvas & brand system

- [ ] 캔버스가 1080×1350 (4:5)인가
- [ ] 좌우 여백이 일관적인가
- [ ] 노란 세로 바와 영문 라벨 위치가 동일한가
- [ ] 제목 역할별 크기·굵기·줄간격이 동일한가
- [ ] 푸터 구분선, 페이지 번호, 크레딧 위치가 동일한가

## 3. Large typography

- [ ] 데크 전체가 `reading-large` 또는 `source-dense-large` 한 프리셋을 쓰는가
- [ ] 일반 본문이 20px 이상인가
- [ ] 오버플로를 맞추기 위해 특정 장만 폰트를 줄이지 않았는가
- [ ] 제목을 맞추기 위해 장별 크기를 바꾸지 않았는가
- [ ] 모바일 25% 축소에서도 본문이 읽히는가

## 4. Text-first adaptive layout

- [ ] 제목·본문 bounding box를 먼저 측정했는가
- [ ] 패널 높이가 실제 텍스트 높이 + 패딩으로 계산됐는가
- [ ] 사진·그래프·도식 영역이 텍스트 계산 후 남은 공간을 사용했는가
- [ ] 글자가 적은 페이지는 패널이 줄고 시각물이 커졌는가
- [ ] 글자가 많은 페이지는 시각물이 줄거나 body-balanced로 전환됐는가

## 5. Fill & whitespace

목표:

```yaml
normal_vertical_fill: 0.86~0.97
panel_utilization: 0.72~0.92
table_vertical_fill: 0.72~0.92
```

- [ ] 140px 이상 연속된 의도하지 않은 빈 띠가 없는가
- [ ] usable height의 10% 이상인 무의미한 빈 영역이 없는가
- [ ] 일반 보고서 페이지에서 본문 끝과 푸터 사이 180px 이상 공백이 없는가
- [ ] panel utilization이 0.65 미만 또는 0.96 초과인 장이 없는가
- [ ] 표지·챕터 오프닝의 여백만 의도적 예외로 표시됐는가

## 6. Page balancing

- [ ] Pass 1 용량 분할을 수행했는가
- [ ] Pass 2 인접 페이지 재균형을 수행했는가
- [ ] underfill 페이지에 다음 페이지의 완전한 문장·문단을 당겼는가
- [ ] overfill 페이지의 마지막 완전한 문장·문단을 다음 장으로 넘겼는가
- [ ] 문장·문단 순서가 유지됐는가
- [ ] 표 행을 중간에서 나누지 않았는가

## 7. Asset intake

- [ ] 모든 업로드 파일이 실제로 열리는가
- [ ] JPG/JPEG, PNG, WebP 이외 형식은 변환 후 검수했는가
- [ ] HEIC/HEIF, TIFF, BMP, GIF 변환 전 원본을 보존했는가
- [ ] 색공간을 sRGB로 통일했는가
- [ ] EXIF 방향을 실제 픽셀에 반영했는가
- [ ] 알파 채널이 필요한 자산의 투명도가 유지되는가
- [ ] 대형 사진 짧은 변 1600px 이상 또는 적절한 작은 슬롯을 사용했는가
- [ ] 저해상도 사진을 무리하게 전면 확대하지 않았는가
- [ ] `ASSET_AUDIT.md`가 존재하는가

## 8. Duplicate & relevance audit

- [ ] SHA-256 완전 중복을 제거했는가
- [ ] perceptual hash 근접 중복을 확인했는가
- [ ] 같은 순간의 근접 중복을 콘택트시트에서 확인했는가
- [ ] 같은 사진이 승인 없이 여러 장에 반복되지 않았는가
- [ ] 사진과 페이지 원문의 의미가 연결되는가
- [ ] 사진이 단순 빈 공간 채움용으로 억지 배치되지 않았는가

## 9. Real photos

- [ ] 실제 사진 전경이 contain·무크롭인가
- [ ] 얼굴, 머리, 손, 발, 결승선, 허들, 배턴이 잘리지 않았는가
- [ ] 남는 영역은 동일 사진 blur/tone-down 배경으로 처리됐는가
- [ ] 긴 본문을 사진 위에 직접 올리지 않았는가
- [ ] 사진 밝기·색온도가 데크 안에서 크게 튀지 않는가

## 10. Image source honesty

- [ ] user-upload와 downloaded-original을 구분했는가
- [ ] 검색 링크만 본 이미지를 실제 사용했다고 주장하지 않았는가
- [ ] 온라인 원본 URL, 제목, 작가, 라이선스, 다운로드 날짜를 기록했는가
- [ ] 권리 상태가 불명확한 이미지는 제외 또는 needs-review로 표시했는가

## 11. Real screenshots & captures

- [ ] 실제 웹페이지·PDF·공식 영상·앱에서 직접 캡처했는가
- [ ] source URL과 페이지 제목을 기록했는가
- [ ] 캡처 날짜를 기록했는가
- [ ] PDF 페이지 또는 영상 시간코드를 기록했는가
- [ ] 문구·숫자·그래프를 변조하지 않았는가
- [ ] 과도한 크롭으로 맥락을 왜곡하지 않았는가
- [ ] 개인정보·알림·계정 정보가 제거 또는 마스킹됐는가
- [ ] 유료 장벽을 우회하거나 기사 전체를 복제하지 않았는가
- [ ] 캡처 해상도가 충분한가

## 12. Charts & tables

- [ ] 그래프가 실제 원문·CSV·XLSX·공식 결과 값만 사용하는가
- [ ] 추정·보간·보기 좋은 숫자 변경이 없는가
- [ ] 축, 단위, 기간, 기준, 출처가 표시됐는가
- [ ] 숫자 근거가 없는 정성 내용을 가짜 수치로 만들지 않았는가
- [ ] 한 장의 그래프 메시지가 하나로 명확한가
- [ ] 3D 그래프를 쓰지 않았는가
- [ ] 표 페이지에 사진이 전혀 없는가
- [ ] 표 폰트가 선택 프리셋으로 전 장 동일한가
- [ ] 표를 맞추기 위해 글자를 줄이지 않았는가
- [ ] 날짜, 기록, 순위, 비고가 원문과 일치하는가

## 13. Diagrams, timelines & maps

- [ ] 도식이 원문에 있는 구조와 인과관계만 표현하는가
- [ ] 원문에 없는 인과관계를 새로 만들지 않았는가
- [ ] 화살표, 수치, 캡션이 코드로 조판됐는가
- [ ] 아이콘 수가 필요한 범위인가
- [ ] 실제 지리 정확도가 필요한 지도는 공식 지도나 좌표 기반인가

## 14. Generated auxiliary visuals

- [ ] 생성 보조 자산이 실제 사진·캡처·데이터·도식으로 해결되지 않는 페이지에만 사용됐는가
- [ ] 전체 페이지가 아니라 별도 에셋으로 생성돼 결정론적 렌더러에 삽입됐는가
- [ ] 스타일이 clean flat 2D인가
- [ ] 분위기가 healthy, calm, friendly인가
- [ ] uncanny/discomfort가 매우 낮은가
- [ ] 폭력, 피, 주사, 수술, 체액, 공포가 없는가
- [ ] 신체·얼굴·손가락 왜곡이 없는가
- [ ] 성적 대상화가 없는가
- [ ] 실제 선수의 가짜 경기·수상 사진이 아닌가
- [ ] 저작권 캐릭터·브랜드를 모방하지 않았는가
- [ ] 생성 이미지 안에 긴 한국어 본문·표·페이지 번호가 없는가
- [ ] 사용자가 생성 기능을 금지한 경우 generated-* 자산이 0개인가

## 15. Visual fallback logic

- [ ] 사진 필수/선호/선택/금지 페이지를 구분했는가
- [ ] 이미지 부족 페이지를 정확히 식별했는가
- [ ] 실제 이미지→캡처→데이터 시각화→도식→저불쾌감 생성 에셋→타이포그래피 순으로 판단했는가
- [ ] 페이지 성격에 맞춰 우선순위를 조정했는가
- [ ] 빈 공간을 의미 없는 장식으로 채우지 않았는가
- [ ] `VISUAL_FALLBACK_LOG.md`에 페이지별 선택과 이유가 기록됐는가

## 16. Source-highlight

- [ ] 원문에 실제 존재하는 문장·수치만 강조했는가
- [ ] 새로운 주장이나 수치를 만들지 않았는가
- [ ] 같은 구절을 본문과 highlight에 중복 표시하지 않았는가
- [ ] text-manifest에는 원문 순서대로 한 번만 기록했는가

## 17. Source-preserving mode

- [ ] 원문의 모든 글자·숫자·괄호·각주·URL이 유지됐는가
- [ ] 문장 순서가 유지됐는가
- [ ] 표 열·행·셀 값이 유지됐는가
- [ ] 페이지 경계가 정확히 이어지는가
- [ ] text-manifest 비교 결과 누락 0인가

필수 수치:

```text
missing_chars: 0
duplicated_chars: 0
order_mismatch: 0
offset_gaps: 0
offset_overlaps: 0
```

## 18. Final visual check

- [ ] 개별 PNG를 100% 확대해 확인했는가
- [ ] 모바일 25% 축소를 확인했는가
- [ ] 전체 콘택트시트에서 서로 다른 템플릿처럼 보이지 않는가
- [ ] 한 장만 유독 글자가 작거나 큰 페이지가 없는가
- [ ] 페이지 번호가 연속적인가
- [ ] 크레딧이 모든 장에 존재하는가
