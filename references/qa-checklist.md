# QA Checklist v3 — Full-deck Render Production

완료 전 아래 항목을 모두 확인한다. 하나라도 실패하면 완료 처리하지 않는다.

## A. 요청 해석과 도구 선택

- [ ] 사용자가 `스킬대로`, `파일로`, `렌더링`, `20장 전체`를 요청했을 때 image_gen을 사용하지 않았는가
- [ ] 파일 렌더링 작업에 10장 생성 제한을 적용하거나 안내하지 않았는가
- [ ] 요청한 전체 장수를 한 실행에서 렌더링했는가
- [ ] 실제 파일 경로가 존재하는지 확인한 뒤 링크했는가

## B. 산출물 완결성

- [ ] `01.png`부터 마지막 페이지까지 개별 PNG가 모두 있는가
- [ ] 파일명이 2자리 숫자 순서인가
- [ ] PNG 일괄 ZIP이 정상적으로 열리는가
- [ ] 전체 preview JPG와 PNG가 있는가
- [ ] `source.txt`가 있는가
- [ ] `text-manifest.txt`가 있는가
- [ ] `page-map.json`이 있는가
- [ ] `asset-map.json`이 있는가
- [ ] `IMAGE_SOURCES.md`가 있는가
- [ ] `QA_REPORT.md`가 있는가

## C. 원문과 페이지 연속성

- [ ] 원문의 모든 글자·숫자·괄호·각주·URL이 유지됐는가
- [ ] 문장 순서가 유지됐는가
- [ ] 표의 열 이름·행 이름·셀 값이 유지됐는가
- [ ] 1~10장과 11~20장의 경계가 정확히 이어지는가
- [ ] 이전 페이지 내용이 다음 페이지에 중복되지 않았는가
- [ ] 페이지 사이 원문 누락 구간이 없는가
- [ ] source_start/source_end 오프셋이 연속적인가
- [ ] `missing_chars: 0`인가
- [ ] `duplicated_chars: 0`인가
- [ ] `order_mismatch: 0`인가
- [ ] `offset_gaps: 0`인가
- [ ] `offset_overlaps: 0`인가

## D. 레이아웃

- [ ] 캔버스가 1080×1350 (4:5)인가
- [ ] 좌우 여백이 일관적인가
- [ ] 노란 세로 바 위치가 동일한가
- [ ] 영문 라벨 위치와 크기가 동일한가
- [ ] 같은 타입의 제목 시작 위치가 동일한가
- [ ] 제목 크기·굵기·줄간격이 동일한가
- [ ] 부제목 크기와 굵기가 동일한가
- [ ] 본문 크기와 줄간격이 동일한가
- [ ] 푸터 구분선, 페이지 번호, 크레딧 베이스라인이 동일한가
- [ ] 본문이나 표가 푸터 영역을 침범하지 않는가

## E. 타이포그래피

- [ ] 제목을 맞추기 위해 크기를 줄인 장이 없는가
- [ ] 본문을 맞추기 위해 크기·자간을 임의 축소한 장이 없는가
- [ ] `body_compact`가 승인된 고밀도 타입에서만 사용됐는가
- [ ] 표 안의 같은 역할 텍스트 크기가 동일한가
- [ ] 긴 제목은 축소가 아니라 줄바꿈으로 해결했는가
- [ ] 모바일 25% 축소에서도 핵심 본문이 읽히는가

## F. 사진 자산

- [ ] 사용자가 준 사진은 실제 업로드 원본을 사용했는가
- [ ] 생성형 도구로 비슷한 사진을 재현하지 않았는가
- [ ] 온라인 사용이라고 기록한 사진은 실제 원본을 다운로드했는가
- [ ] 검색 썸네일이나 페이지 캡처를 원본처럼 사용하지 않았는가
- [ ] SHA-256 중복이 0개인가
- [ ] perceptual hash 근접 중복을 검토했는가
- [ ] 승인 없이 같은 사진을 두 번 사용하지 않았는가
- [ ] 사진과 해당 페이지 내용이 연결되는가
- [ ] 얼굴, 머리, 손, 발, 결승선, 허들, 배턴 등 핵심 요소가 보존됐는가
- [ ] 전경 사진이 무크롭 contain 방식인가
- [ ] 블러 배경은 전경 사진의 빈 공간 채움에만 사용됐는가
- [ ] 사진 밝기와 색온도가 데크 안에서 크게 튀지 않는가

## G. 표와 데이터

- [ ] 모든 `table` 페이지에 사진이 없는가
- [ ] 표 뒤에 인물 또는 경기 장면이 깔리지 않았는가
- [ ] 표가 웜화이트 단색 배경인가
- [ ] 표가 얇은 선과 정렬 중심으로 구성됐는가
- [ ] 표를 맞추기 위해 글자를 지나치게 줄이지 않았는가
- [ ] 단위, 날짜, 기록, 순위가 원문과 일치하는가
- [ ] 표가 넓으면 행·열 순서를 유지한 채 분할했는가

## H. 이미지 출처와 정직성

- [ ] 사용자 제공 이미지는 `user-upload`로 기록했는가
- [ ] 실제 온라인 다운로드 이미지만 `downloaded-original`로 기록했는가
- [ ] 온라인 파일의 원본 URL과 파일 페이지 URL이 있는가
- [ ] 작가·라이선스·다운로드 날짜가 있는가
- [ ] 다운로드하지 않은 이미지를 검색해서 사용했다고 주장하지 않았는가
- [ ] 권리가 불명확한 이미지는 명시했거나 제외했는가

## I. 전체 시각 검수

- [ ] 모든 개별 PNG를 100%로 확인했는가
- [ ] 모바일 축소본을 확인했는가
- [ ] 전체 콘택트시트에서 하나의 디자인 시스템으로 보이는가
- [ ] 한 장만 유독 글자가 작거나 큰 페이지가 없는가
- [ ] 페이지 번호가 연속적인가
- [ ] 사진 페이지와 표 페이지의 전환이 자연스러운가
- [ ] 의미 없는 빈 공간이나 억지 장식이 없는가

## J. 완료 보고

- [ ] 총 페이지 수를 정확히 적었는가
- [ ] `deterministic file rendering` 방식임을 적었는가
- [ ] 사진이 사용자 제공인지 실제 다운로드인지 구분했는가
- [ ] 표 페이지 번호를 적었는가
- [ ] 이미지 중복 검사 결과를 적었는가
- [ ] 원문 누락 검사 결과를 적었는가
- [ ] ZIP, preview, manifest, sources, QA 링크를 모두 제공했는가
