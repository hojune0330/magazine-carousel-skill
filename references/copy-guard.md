# Copy Guard — 원문 보존 규칙

사용자가 `원문 그대로`, `한 글자도 빼지 말 것`, `단어·문장·표를 모두 유지`라고 지시하면 아래 규칙을 강제한다.

## 허용

- 페이지 분할
- 줄바꿈
- 표의 시각적 행·열 구성
- 페이지 번호와 크레딧 추가

## 금지

- 문장 삭제
- 단어 삭제
- 맞춤법 교정
- 띄어쓰기 교정
- 인명 교정
- 수치 교정
- 괄호/각주 제거
- URL 축약
- 문장 순서 변경
- 요약 또는 재작성

## 누락 검수

1. 원문 전체를 `source.txt`로 보관한다.
2. 페이지별 텍스트를 순서대로 `text-manifest.txt`에 기록한다.
3. 디자인용 줄바꿈과 페이지 번호/푸터를 제외하고 원문 문자열과 매니페스트 문자열을 비교한다.
4. 한 글자라도 다르면 완료 처리하지 않는다.
5. 공간이 부족하면 장수를 늘린다. 본문 글자 크기를 줄이지 않는다.

## 의심되는 원문 오류

원문에 사실 오류, 오탈자, 중복, 잘못된 날짜가 의심돼도 원문 보존 모드에서는 고치지 않는다. 필요하면 별도의 `QA NOTE`에서만 지적한다.
