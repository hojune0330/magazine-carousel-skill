# Asset Production Extension v3.3

현재 공정은 `production-workflow.md`가 기준이다. 과거 v3.2의 사진 우선 확장 규칙보다 v3.3의 본문 우선·관객 노출층 분리 규칙이 우선한다.

읽을 문서:

- `image-research-and-placement.md`: 페이지별 니즈 → 자료 조사 → 권리·중복·품질 → 배정.
- `asset-intake-and-visual-fallback.md`: 파일 형식과 대체 보조물.
- `audience-content-boundary.md`: 무엇을 실제 슬라이드에 그리는지.

입력 감사와 이미지 조사 기록은 production/ASSET_AUDIT.md, VISUAL_FALLBACK_LOG.md, IMAGE_SOURCES.md에 둔다. 그 문서의 헤더·파일 안내·검수 메모를 슬라이드에 삽입하지 않는다.

원문의 모든 글자·원래 표를 먼저 배치한다. 사진이 본문을 밀면 사진을 줄이거나 없앤다. 새 차트·도식도 본문을 대체하지 않는다. 표에는 사진을 넣지 않는다. 생성형 AI 에셋 금지와 정확한 코드 그래프 렌더링은 구분한다.
